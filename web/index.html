近期客户端

流量统计 HY2 UDP 与已安装 VLESS TCP 端口的合计值，包含协议开销；方向以客户端为准，不包含网站及其他服务。

客户端流量

按公网 IP 统计，并分别控制上传和下载上限。

“有流量”表示最近一个采样周期内有数据包，不等于已认证在线。相同公网 IP 的设备与两种协议共用合计限速。累计值从规则建立起计算，重启或计数重建会清零，单方向空闲 24 小时后过期。

设置 IP 限速

0 表示不限速。100 Mbps = 12.5 MB/s。限速允许短时突发；超额数据包会被丢弃，实际应用速度可能低于设置值。

连接与导出

为你的客户端选择合适的导入格式。

导出内容包含节点密码，只分享给你信任的设备。Hiddify 和 v2rayN 可直接从剪贴板导入节点链接；完整订阅包含所有已安装协议。
